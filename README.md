# 🌐 Yolanda Services Website

![Yolanda Logo](assets/images/logo.png)

A modern, responsive, and professional corporate website developed for **Yolanda Services**.

The website showcases the company's services, provides information about the organization, and offers an engaging user experience with smooth animations, responsive layouts, and a clean modern interface.

---

# 🚀 Features

- Modern responsive design
- Animated splash/loading screen
- Smooth scrolling navigation
- Animated statistics
- Scroll reveal animations
- Hero section with floating logo
- Professional service cards
- About section
- Why Choose Us section
- Client showcase
- Testimonials
- Newsletter subscription
- Contact section
- Mobile-friendly layout
- SEO-ready structure
- Optimized performance
